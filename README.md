# Mi Negocio Rentable

App para pequeños comerciantes: compras, ventas, inventario, fiados y cierre de caja por voz.
Abre https://ehuanca326.github.io/mi-negocio-rentable/ en Chrome para Android, toca «Instalar la app» y regístrate.

Mientras `js/config.js` no tenga un proyecto Supabase, la app funciona en **modo local**: cada persona guarda sus datos solo en su celular.
